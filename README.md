## 📌 Sobre o Projeto
O **AnimalLife** é um sistema desenvolvido como **Trabalho de Conclusão de Curso (TCC)** do curso de **Engenharia de Software** no **Centro Universitário Assis Gurgacz (FAG)**.

O projeto tem como objetivo o **monitoramento e gerenciamento de informações relacionadas a animais**, permitindo o cadastro, visualização e acompanhamento de dados relevantes, como espécie, raça, sexo, peso, temperatura e registros associados.

A aplicação foi desenvolvida utilizando uma arquitetura moderna, separando claramente as responsabilidades entre **Front-End** e **Back-End**, garantindo organização, escalabilidade e manutenção do sistema.

## 📌 About the Project
**AnimalLife** is a system developed as a **Final Graduation Project (TCC)** for the **Software Engineering** program at **Centro Universitário Assis Gurgacz (FAG)**.

The project aims to provide a system for **monitoring and managing animal-related information**, allowing the registration, visualization, and tracking of relevant data such as species, breed, sex, weight, temperature, and related records.

The application was built using a modern architecture with a clear separation between **Front-End** and **Back-End**, ensuring better organization, scalability, and maintainability.
